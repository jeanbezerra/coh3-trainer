# Visual identity prompt

Use case: logo-brand

Asset type: reusable Windows desktop application icon for a family of PC game trainer utilities

Primary request: create one original, universal trainer-software emblem: a compact rounded-square dark gunmetal badge containing a bold geometric shield combined with a small upward chevron and three minimal control-bar notches, suggesting control, progression, and precision without referencing any specific game

Style/medium: polished vector-like app icon, flat layered shapes, crisp hard edges, extremely legible at 16x16 pixels

Composition/framing: single centered symbol, perfectly square, balanced symmetry, generous internal padding, strong silhouette

Color palette: charcoal and brushed steel gray, bright white highlights, one restrained emerald-green accent matching a connected/active state

Lighting/mood: subtle premium metallic depth only, professional and technical

Constraints: genuinely transparent canvas outside the rounded-square badge; no text, no letters, no numbers, no game logos, no trademarks, no characters, no weapons, no watermark, no background scene, no thin details, no excessive gradients; keep all important detail inside a central safe area suitable for cropping to Windows ICO sizes
